Privacy Policy

Cold Case FC Uploader · Effective 10 November 2026

Who we are

Cold Case FC is a YouTube channel that tells true football stories (youtube.com/@ColdCaseFC). Cold Case FC Uploader ("the app") is a private tool used only by the channel's owner to publish the channel's own videos. It is not offered to anyone else.

What the app accesses

The app signs in with Google OAuth and uses the YouTube Data API with the youtube.force-ssl permission. It works only on the channel owner's own YouTube channel, to:

  • upload videos and set their titles, descriptions, tags, language and publish time;
  • add caption tracks, title and description translations, and thumbnails;
  • create playlists and add the channel's videos to them;
  • update the channel's description, translations, banner and trailer;
  • read the channel's own videos and caption tracks to check that each step worked.

What the app does not do

The app does not access anyone else's account, does not collect data about viewers, does not show ads, and does not sell, share or transfer Google user data to third parties. Google user data is not used for advertising or to train AI models.

Storage and security

The app has no server and no database. Google's sign-in result is stored only as a refresh token in a local file on the owner's own computer, which is never shared or published. Videos and their details are sent only to YouTube.

Google API Services User Data Policy

Cold Case FC Uploader's use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The app uses YouTube API Services. Use of YouTube through the app is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time on the Google security settings page: security.google.com/settings/security/permissions. Deleting the local token file removes the app's stored access. Videos already uploaded remain on YouTube under YouTube's own terms and can be deleted in YouTube Studio.

This website

This site is a set of static pages hosted on GitHub Pages. It uses no cookies, analytics or forms. GitHub may process technical data, such as IP addresses, when serving the pages; see the GitHub General Privacy Statement.
